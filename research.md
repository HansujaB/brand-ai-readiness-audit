# Research behind the Brand AI Readiness Audit

This marketplace combines freshness, engagement, crawl/render and orchestration checks. The table connects the research to concrete implementation decisions, with an emphasis on useful findings and fewer false positives for business owners.

| Audit area | Research / source | How we applied it |
|---|---|---|
| **Freshness — offer expiry** | Google: [Product snippets](https://developers.google.com/search/docs/appearance/structured-data/product-snippet) | Check explicit `priceValidUntil` dates. An expired field is a metadata issue; missing dates do not prove stale content. |
| **Freshness — comparable prices** | Google: [Product variants](https://developers.google.com/search/docs/appearance/structured-data/product-variants) | Preserve product identity, variant, currency, region and offer conditions before comparing claims. Different products or scopes are not automatically contradictions. |
| **Freshness — article dates** | Google: [Publication dates](https://developers.google.com/search/docs/appearance/publication-dates) and [date guidance blog](https://developers.google.com/search/blog/2019/03/help-google-search-know-best-date-for) | Compare equivalent visible and structured update dates for the same article. Do not confuse publication with modification or recommend changing dates merely to appear fresh. |
| **Engagement — usable actions** | Playwright: [Actionability](https://playwright.dev/docs/actionability) and [device emulation](https://playwright.dev/docs/emulation) | Inspect visibility, enabled state, overlapping elements and desktop/mobile behavior. A button's presence alone does not establish a usable journey. |
| **Engagement — reading and touch** | W3C WCAG: [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) and [Target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) | Identify overflowing text and small controls with element evidence. Respect table, spacing and target-size exceptions; this is not an accessibility certification. |
| **Engagement — performance** | web.dev: [Cumulative Layout Shift](https://web.dev/articles/cls) | Aggregate observed layout shifts using session windows. Label measurements as instrumented lab samples; do not present them as real-user performance or bounce rates. |
| **Crawl — crawler permissions** | IETF: [Robots Exclusion Protocol, RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html) | Respect robots rules before fetching pages and redirects. Separate search permissions from training permissions; audit-only exclusions become coverage limitations. |
| **Crawl — index and snippet controls** | Google: [Robots directives](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag); Bing: [supported tags](https://www.bing.com/webmasters/help/robots-meta-tags-and-attributes-that-bing-supports-5198d240) | Preserve crawler scope and case-insensitive directives. Distinguish `noindex` from `max-image-preview:none`; inspect snippet controls and PDF response headers. |
| **Crawl — page discovery** | Google: [Sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [canonicals](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls); WHATWG: [base URL](https://html.spec.whatwg.org/multipage/semantics.html#the-base-element) | Use sitemap URLs and normal links, resolve relative URLs correctly, count unique final pages and inspect conflicting canonical declarations. |
| **Crawl — structured data** | WHATWG: [Microdata](https://html.spec.whatwg.org/multipage/microdata.html); W3C: [RDFa primer](https://www.w3.org/TR/rdfa-primer/) | Preserve nested entities and repeated properties alongside JSON-LD. Compare explicitly identified offers; disclose unsupported semantic constructs. |
| **Render — JavaScript content** | Google: [JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics); Playwright: [route limitations](https://playwright.dev/python/docs/api/class-browsercontext#browser-context-route) | Compare raw and rendered content/metadata. Incomplete rendering stays unknown. Abort redirect replay that could bypass interception and retain safely fetched HTTP evidence. |
| **Fact context / AI readability** | Anthropic engineering blog: [Contextual Retrieval](https://www.anthropic.com/engineering/contextual-retrieval) | Retain headings, entities, units and supplied qualifications around fact excerpts. Do not attach unrelated footer conditions. This motivates context preservation, not a claim to reproduce Anthropic's results. |
| **Orchestration — resilient execution** | Google SRE: [Handling Overload](https://sre.google/sre-book/handling-overload/); SQLite: [Atomic Commit](https://www.sqlite.org/atomiccommit.html) | Bound stages, isolate failures and checkpoint completed evidence. These reliability principles inform the design; our JSON checkpoints do not implement SQLite transactions. |
| **Collection — network safety** | OWASP: [SSRF prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html); urllib3: [custom SNI](https://urllib3.readthedocs.io/en/stable/advanced-usage.html) | Reject private destinations and encoded transactional paths. Connect to validated public IPs while preserving TLS hostname verification. |
| **Corroboration and owner output** | Adobe problem statement; [JSON Schema validation](https://json-schema.org/understanding-json-schema/reference/array) | Use explicit source ownership/grouping for imported evidence; copies are not independent confirmations. Return concise findings, actions and coverage, with detailed diagnostics separately. These are implementation choices, not research-proven scoring rules. |

**Evidence boundary:** Missing information is not automatically a defect. The audit does not claim universal semantic fact-checking, actual AI citations, ranking gains or completed transactions. Time, page and download budgets and severity levels are engineering choices, not numbers prescribed by these sources.

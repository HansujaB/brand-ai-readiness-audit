# Freshness review checklist

- Use explicit product identity, currency and offer scope before price comparison. Never use the brand as a missing product identity.
- Check explicit offer expiry against observation date; describe stale metadata without claiming the offer is purchasable.
- Compare article modification dates only with an explicitly labelled update date for the same page. Publication dates and event dates are different facts.
- Missing dates, old dates, missing schema and absent external confirmation are not automatic findings.
- Preserve variant, market, historical and offer-condition differences as uncertainty or valid differences.
- Imported sources need reviewed ownership and source-group annotations. No automatic live search occurs.
- Return compact findings with exact evidence and a practical correction; preserve sample limitations. Detailed evidence stays in diagnostics.
- User-supplied extraction questions retain the existing shared evaluator; prose policy verification and rendered-only freshness are not implemented in this step.

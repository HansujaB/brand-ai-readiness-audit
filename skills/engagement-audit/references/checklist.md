# Visitor-question review

| Purpose | Questions to adapt to the website |
|---|---|
| Homepage, including regional roots | What is offered, for whom, and where should this visitor go next? |
| Product | What does it cost, does it fit the requirement, and which delivery/return conditions apply? |
| Pricing | What is included, what is the billing commitment, and how do options compare? |
| Returns/delivery | What eligibility, location, timeframe, charge and exception apply? |
| Service/support | What help is available, where, and how can the visitor reach the appropriate public information? |
| Documentation/article | Does the content answer the named task, and is the next relevant section reachable? |

For each question, inspect a coherent source section and the specifically labelled destination. Check product/service identity and locale at both ends. Lexical matches remain answer candidates. An HTTP 200, unrelated contact link or long paragraph does not prove the task is answered.

Separate text evidence, visual geometry, absence and interaction reliability. Preserve stable observations after unrelated resource failures. Record labels, locators, viewport, bounds and blocking elements for visual issues. Check prerequisite selections, consent, scroll position and appropriate target-size/reflow exceptions.

Use only public read-only navigation, explicit GET search, keyboard focus and local disclosure states. Keep transactional and authenticated workflows outside the sample. Preserve a concrete next investigation for any important unanswered question.
